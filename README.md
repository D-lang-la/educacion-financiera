# 🪙 Educación Financiera para Jóvenes - Sitio Web Informativo

## 📌 Descripción del Proyecto
Plataforma web educativa para jóvenes sobre finanzas personales, gestión de presupuestos, ahorro, crédito, inversiones y autoevaluación interactiva.

## 🚀 Funcionalidades Principales
* **Navegación Multipágina:** Conexión fluida entre Inicio, Presupuesto, Inversiones y Autoevaluación.
* **Diseño Responsivo:** Adaptado a dispositivos móviles, tablets y computadoras utilizando CSS Grid y Flexbox.
* **Recursos Visuales:** Integración de imágenes optimizadas e ilustrativas (`.jpg`) organizadas en activos.
* **Buscador Dinámico (JS):** Filtra tarjetas informativas en tiempo real según la palabra clave ingresada por el usuario.
* **Quiz Interactivo (JS):** Módulo de autoevaluación que valida los conocimientos adquiridos con retroalimentación inmediata.

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica de las páginas.
* **CSS3:** Estilos visuales, maquetación responsiva y diseño de componentes.
* **JavaScript Vanilla:** Lógica para la búsqueda de contenido y evaluación del cuestionario.
* **Git & GitHub:** Control de versiones y despliegue del sitio.
